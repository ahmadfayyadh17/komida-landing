# KOMIDA Landing Page

Laman rasmi **Koperasi MIDA Kuala Lumpur Berhad (KOMIDA)**.

**Live:**
- Primary: https://komida.com.my/
- Fallback: https://ahmadfayyadh17.github.io/komida-landing/

## Pages
- `index.html` — laman utama
- `berita.html` — berita & pengumuman
- `borang.html` — muat turun borang
- `alp.html` — ahli lembaga pengarah
- `sjc.html` — Skim Jimat Cermat
- `takaful.html` — Insurans & Takaful
- `bazar.html` — Bazar KOMIDA

Static site — no build step. Open `index.html` in any browser to preview.

## Deploy (GitHub Pages)
Push all files in this folder to the repo root of `komida-landing` (branch `main`, source `/root`).
The `CNAME` file pins the site to `komida.com.my` — see `DEPLOY-DNS.md` for DNS details.
