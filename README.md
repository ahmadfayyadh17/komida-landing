# KOMIDA Landing Page

Landing page rasmi untuk **Koperasi MIDA Kuala Lumpur Berhad (KOMIDA)**.

## Quick start

This site is a single static HTML file — no build step required.

- `index.html` — the full landing page (logo embedded as inline SVG, fonts loaded from Google Fonts CDN)

To preview locally, just open `index.html` in any browser.

## Live deploy via GitHub Pages

1. Create a new public repo on GitHub (e.g. `komida-landing`).
2. Upload `index.html` and `README.md` to the repo root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
5. Choose branch **`main`** and folder **`/ (root)`**, then **Save**.
6. After ~1 minute your site is live at:
   `https://<your-username>.github.io/komida-landing/`

## Theme

- Primary: deep navy blue (`#1e3a8a`)
- Accent: bright blue (`#3b82f6`)
- Signal: red (`#dc2626`) — preserved from logo chevron
- Greys: slate `#0f172a` / `#1e293b` / `#64748b`
- Backgrounds: white + cool grey mist `#f1f5f9`
